# Figures

Every published figure in one place. `manifest.csv` maps each figure (and panel)
to the code that generates it.

```
main/            Main-text Figures 1-6 (panels named "Figure <N><panel>. <desc>.png")
supplementary/   Supplementary Figures S1-S18 (figure_sNN[_amp/azt].png)
diagnostics/     Non-manuscript renders: regression/{amp,azt}/ learning-curve/SHAP/
                 permutation panels, and exploratory/ distribution plots
```

## How each figure is regenerated

Most figures regenerate from this repository's code and data:

- **Main panels** — `src/05_epistasis_figures.ipynb` (Figs 3-4 + SI panel S5), plus
  `src/03`/`src/04` (Fig 5 SHAP), `src/figure_scripts/figure_3a.py` (Fig 3A), and
  `src/graph_analysis/summary-stats.ipynb` (Fig 1E global-fitness ridgelines).
  Rerunning writes back into `figures/main/` and `figures/supplementary/`.
- **Supplementary S9-S17** — the self-contained modules under `analysis/`. Each
  `analysis.py` writes its published panel(s) directly into `figures/supplementary/`
  (secondary diagnostic panels stay in the module's own `figures/`, gitignored).
- **S2, S3** — reproducing code + data folded in under `si_figures/` (see each folder's README).

A few figures are produced with external tools or by collaborators and cannot be
regenerated by this repository's code alone (noted in `manifest.csv`):

- **Fig 2, S4** — graph data from `src/graph_analysis/` laid out in **Gephi**.
- **Fig 1** — panel E (global-fitness ridgelines) from `src/graph_analysis/summary-stats.ipynb`;
  schematic panels A/B/D created with **BioRender** (publication license); panel F is a
  structural render / ChemDraw artwork (no plotted data).
- **S1** — clinical mutational spectrum; external NCBI analysis with no in-repo
  generator (see Data Availability).
- **Fig 6, S6** — DCA/LGL evolutionary statistics; the DCA panels (6A-C,G-H and S6) are
  reproduced by `src/evolutionary_statistics/reproduce_fig6.py` with source data under
  `src/evolutionary_statistics/source_data/`. The LGL panels 6D-F come from the separate
  `github.com/morcoslab/LGL-VAE` model (deposited coordinates on Dryad).
- **S18** — graph-analysis peak-absorption diagnostic (Devin Meng).
- **S2** — MIC panel; the reproducing data + estimation code are in `si_figures/s02_mic/`.
  The deposited panel image is the published version.

See `manifest.csv` for the full figure -> generator table.
