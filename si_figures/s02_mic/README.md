## Provenance (UTSW BioHPC)

Source: `/project/greencenter/Toprak_lab/shared/plategig/projects/Tested_Variants_MIC_Estimations/`.
`CML_MIC_estimations.ipynb` is the confirmed generator — its `PlateInfo` sheet contains all 10
strain names in the manuscript figure (`NEB10B`, `TEM-1`, `TEM-1-CML`, and the seven named
multi-mutant select variants). The sibling `SML_MIC_estimations.ipynb` points at a different,
later plate run (Ilona's separate validation project → Supplementary Figs S7/S8) and is **not**
this figure.

## Dependency: `plategig`

The notebook uses the lab's MIC/IC50 fitting package **`plategig`**
(<https://github.com/msadikyildiz/plategig>, MIT), pinned to the `biohpc`-branch commit
`2d9e7d9` — the API this notebook targets (the default `main` branch has a different,
incompatible API, missing `convert_OD_plate_to_long` / `plot_single_plate_media_only_wells`).
It is an **optional** dependency (`[project.optional-dependencies].si-figures`) so the main
pipeline does not require it.

**Requires Python >= 3.12** (plategig's floor): the `si-figures` extra is marked
`python_version >= '3.12'`, so on a 3.10/3.11 interpreter it resolves to nothing and the
`import plategig` below fails. Run this notebook under a 3.12+ interpreter:

```bash
uv sync --extra si-figures      # under Python 3.12+ (see the repo's .python-version)
```

## Path ports

The notebook's first cell was changed from the BioHPC absolute paths to repo-relative:
`PROJECT_PATH = Path.cwd()`, `PROJECT_ID = '.'` (run it from this directory). `import plategig`
resolves from the installed package. Also removed 12 leftover cells from an unrelated
Levofloxacin/Amikacin experiment, and reordered two out-of-order interactive cells so the
notebook runs top-to-bottom (both diagnostic-only; no computation changed).

## Reproducibility

`uv run --extra si-figures jupyter nbconvert --to notebook --execute CML_MIC_estimations.ipynb`
computes `growth_features` (73 rows) with the correct TEM-1 spectrum (high ampicillin MIC,
low 3rd-gen-cephalosporin/carbapenem MIC). `plategig`'s confidence intervals use an unseeded
bootstrap, so exact CI bounds vary run-to-run (same order of magnitude) — a property of the
upstream package, not this import.

## Figure note

The confirmed notebook produces a **faceted** layout ("MIC combined.png"), while the published
`figures/supplementary/figure_s02.png` is a **single-panel** view titled "MIC Values by Strain
and Antibiotic (Median ± Range)". The exact single-panel script was not on BioHPC. Because the
underlying data is fully reproduced here and the published figure is peer-reviewed, the
published `figure_s02.png` is retained verbatim; this folder provides its reproducing data +
estimation code.
