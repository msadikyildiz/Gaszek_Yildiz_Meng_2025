## Reproducibility status - VERIFIED, runs end-to-end

Ran via `uv run jupyter nbconvert --to notebook --execute --inplace` in this
repo's existing `uv` environment - **no new dependencies were needed**
(`altair`, `seaborn`, `openpyxl`, etc. were already in `pyproject.toml`).
Confirmed:

- `growth_features` (the fitted IC50/MIC table, 73 rows) computes
  successfully and matches the manuscript's strains/antibiotics/order of
  magnitude, e.g. TEM-1 x Ampicillin MIC ~= 3.8x10^4-7.9x10^4 ug/mL across two
  independent runs (this repo's run vs. the notebook's own cached BioHPC
  output) - same order of magnitude and qualitative story (TEM-1 highly
  resistant to ampicillin, NEB10B sensitive), but **not bit-identical between
  runs**. `growth_features` has an `ic50_bootstrap` column - `plategig`'s
  phenotyper uses unseeded bootstrap resampling for its confidence intervals,
  so exact CI bounds (and to a lesser extent point estimates) vary run to
  run, including presumably on BioHPC itself. This is a property of the
  upstream `plategig` package, not something introduced by this import.
- The confirmed BioHPC cell (`alt.vconcat()` Altair chart, one facet per
  antibiotic, colored by strain) reproduces `figures/MIC combined.png`,
  visually consistent with `reference/MIC_combined_biohpc_original.png`.

## Figure layout - important caveat, please review

The BioHPC notebook's own plotting cell (confirmed, unmodified logic)
produces a **faceted** layout: 9 stacked subplots, one per antibiotic,
x = Strain, colored by strain. This is `figures/MIC combined.png`.

The **current manuscript placeholder** `figures/supplementary/figure_s02.png`
(a DOCX extraction) instead shows a **single panel**: x = Strain, colored by

MIC_estimations.ipynb`), no script producing that exact single-panel

cells reconstruct the single-panel layout from that same confirmed data
(`growth_features.to_csv(...)` then a matplotlib reconstruction, output as
`figures/MIC_single_panel_reconstruction.png`) - clearly marked in the
notebook as an addition, not a recovered original. **`figures/supplementary/
figure_s02.png` was left unchanged** (not overwritten) pending your decision:

- (a) keep the current placeholder's exact pixels (already correct/published) and
  just cite this notebook as the reproducing source code, or
- (b) swap in the code-generated `MIC_single_panel_reconstruction.png` once

  `MIC_ci_lower`/`MIC_ci_upper` bootstrap-CI columns used here (plausible,
