# Supplementary Figure S2 — MIC panel for TEM-1-CML and select variants

Caption: "Minimum inhibitory concentrations (MICs) for TEM-1CML and select
variants against a panel of β-lactams. MICs determined for NEB10B …"

## Overview

`CML_MIC_estimations.ipynb` fits MIC/IC50 values from broth-microdilution
optical-density data and renders the S2 panel. Its `PlateInfo` sheet covers all
10 strains in the manuscript figure: `NEB10B`, `TEM-1`, `TEM-1-CML`, and the
seven named multi-mutant variants.

## Contents

```
CML_MIC_estimations.ipynb   fitting + figure notebook
data/
  PlateInfo_250508_250510_250407.xlsx   plate layout (strain / antibiotic / well map)
  ODFinal_250508_250510_250407.xlsx     raw optical-density readings
  growth_features.csv                   fitted IC50/MIC table (regenerated by the notebook)
reference/
  MIC_combined_biohpc_original.png      faceted MIC layout (one panel per antibiotic), for comparison
```

## Dependency: `plategig`

The notebook uses the MIC/IC50 fitting package **`plategig`**
(<https://github.com/msadikyildiz/plategig>, MIT), pinned to the `biohpc`-branch
commit `2d9e7d9`, whose API provides `convert_OD_plate_to_long` /
`plot_single_plate_media_only_wells` (absent from the default `main` branch). It
is an **optional** dependency (`[project.optional-dependencies].si-figures`), so
the main pipeline does not require it.

**Requires Python >= 3.12** (plategig's floor): the `si-figures` extra is marked
`python_version >= '3.12'`, so on a 3.10/3.11 interpreter it resolves to nothing
and `import plategig` fails. Run the notebook under a 3.12+ interpreter:

```bash
uv sync --extra si-figures      # under Python 3.12+ (see the repo's .python-version)
```

## Inputs and paths

The notebook resolves inputs relative to its own directory
(`PROJECT_PATH = Path.cwd()`, `PROJECT_ID = '.'`); run it from this folder.
`import plategig` resolves from the installed package.

## Reproduction

```bash
uv run --extra si-figures jupyter nbconvert --to notebook --execute CML_MIC_estimations.ipynb
```

computes `growth_features` (73 rows) with the expected TEM-1 spectrum: high
ampicillin MIC, low third-generation-cephalosporin / carbapenem MIC. `plategig`'s
confidence intervals use an unseeded bootstrap, so exact CI bounds vary
run-to-run within the same order of magnitude — a property of the upstream
package.

## Figure note

The notebook renders a single-panel MIC figure (strain on the x-axis, coloured
by antibiotic) matching the manuscript's `figure_s02.png` layout, written to
`figures/MIC_single_panel_reconstruction.png`. The faceted alternative
(`reference/MIC_combined_biohpc_original.png`, one subplot per antibiotic) is
drawn from the same fitted `growth_features` table.
`figures/supplementary/figure_s02.png` is the published S2 panel; the single-panel
cell here reconstructs the same layout from the fitted table.
